1. OVERVIEW AND INTRODUCTION
================================================================================

1.1 What is the CAPEX Reporting Tool?

The CAPEX Reporting Tool is a desktop application designed to help users process and manage CAPEX data efficiently. The tool automatically converts and formats financial data into standardized Excel files with embedded formulas for easy calculation and modification.

1.2 A Tool for

- Teams managing CAPEX reporting
- Personnel processing procurement and financial data
- Anyone working with CJI, RFP, Reclass, ZMM, or WP LOA reports
- Excel and financial data management teams

1.3 Can help for

- Data processing → Converts large files in seconds instead of minutes
- Formula retention → Output files contain editable Excel formulas, not static values
- Multiple file formats supported → Works with CJI5, CJI3, RFP, Reclass, ZMM, and WP LOA files
- Cross-platform → Available for both Windows and macOS
- Automatic updates → Receives new features and improvements automatically
- Data validation → Checks files before processing to ensure compatibility

1.4 Application Features

The tool supports processing and conversion for six different file types:

- WP LOA Report → Handles allocation and approval level data
- CJI5 → Processes CJI5 financial reference documents
- CJI3 → Processes CJI3 financial reference documents
- RFP → Manages request for payment data
- Reclass → Reclassifies financial entries between categories
- ZMM → Handles procurement and PR (Purchase Requisition) reference data

3. Find CAPEX_Reporting_Tool in the list

7. HOW TO USE EACH FEATURE
================================================================================

7.1 General Processing Steps (All File Types)

Every file type follows the same basic workflow:
1. Click on the appropriate tab
2. Click the "Browse File" button to select your Excel file
3. Review any available options for that file type
4. Click the "Process File" button
5. Select where to save the processed file
6. Wait for processing to complete

7.2 Feature 1: WP LOA Report Processing

7.2.1 What is WP LOA?
Work Package Line of Approval (WP LOA) reports contain project and equipment 
authorization data with approval levels.

7.2.2 When to Use
Use this feature when you have a WP LOA Excel file that needs formula-based 
processing for VLOOKUP automation and data enrichment.

7.2.3 Step-by-Step Instructions

1. Open the CAPEX Reporting Tool application
2. Click on the "WP LOA Report Processing" tab
3. Click the "Browse File" button under "Step 1: Select WP LOA Report File"
4. Browse to and select your WP LOA Excel file
5. Click "Open"
   - The file name appears in the application
6. (Optional) Load external reference files:
   - Click "Browse" next to "CAPEX AVAILMENT File" (if you have one)
   - Click "Browse" next to "LOA Current Approver File" (if you have one)
7. Review processing options if available
8. Click the "Process WP LOA Report" button
9. A save dialog opens
10. Choose a location where you want to save the processed file
11. Enter a name for the output file (or accept the default)
12. Click "Save"
13. Processing begins (status bar shows progress)
14. Success message appears showing processed file name and row count

7.2.4 Output Format

- New Excel file with "WP_LOA_Processed" in the filename
- Original data with added columns (K through AB) containing formulas
- Formulas include:
  - PID extraction and concatenation
  - VLOOKUP formulas for BUDGET sheet references
  - Division mapping formulas
  - PROPONENT name formatting
- All formulas allow for recalculation and modification in Excel
- Estimated Time of Processing: 10-15 seconds

7.2.5 Important Notes:

- The tool auto-detects reference files (CAPEX AVAILMENT, LOA CURRENT APPROVER)
- If files are in the same folder as WP LOA Report, they are found automatically
- Make sure reference files have the BUDGET sheet in the WP LOA file
- All VLOOKUP formulas use IFERROR() for safe lookups (returns "N/A" if no match)

7.3 Feature 2: CJI5 Processing

7.3.1 What is CJI5?
CJI5 is a financial reference document containing transaction data with currency 
information.

7.3.2 When to Use
Use this feature when you need to convert CJI5 data and apply currency conversion 
formulas (PHP and SGD to USD).

7.3.3 File Requirements

Your CJI5 file must contain these columns:
- Reference Document number
- Transaction Currency (PHP, SGD, USD, or other)
- Value/Amount field
- Additional reference information

7.3.4 Step-by-Step Instructions

1. Open the CAPEX Reporting Tool application
2. Click on the "CJI5" tab under "Basic Processing (STEP 4-5)"
3. Click the "Browse File" button
4. Select your CJI5 Excel file
5. Click "Open"
6. Verify the file is recognized (file name appears in the application)
7. Click the "Process File" button
8. In the save dialog:
   - Choose where to save the file
   - Enter a filename or use the default "CJI5_Processed_[date]_[time]"
   - Click "Save"
9. Processing starts (now very fast - usually 1-2 seconds)
10. Success message appears showing:
    - Output filename
    - File size in MB
    - Number of rows processed
    - Confirmation that formulas are retained

7.3.5 What the Processing Does

- Validates all reference documents are in correct format
- Adds new column: Amount_USD
- Creates formula: Converts currency to USD using rates (PHP: 57, SGD: 1.34)
- Formula allows users to modify amounts and recalculate automatically in Excel
- Preserves all original data
- No yellow subtotal rows receive formulas (blank cells)

7.3.6 Currency Conversion Formula

=IF(UPPER(Currency)="PHP", Amount/57, IF(UPPER(Currency)="SGD", Amount/1.34, Amount))

This means:
- If currency is PHP: divide amount by 57 to get USD
- If currency is SGD: divide amount by 1.34 to get USD
- If currency is USD or other: keep amount as is

7.3.7 Output Format

- File named: CJI5_Processed_[date]_[time].xlsx
- Contains original data plus new USD Amount column
- All formulas editable in Excel
- Ready for further analysis or reporting
- Estimated Time of Processing: 2-5 seconds

7.3.8 Advanced: CJI5 with Pivot Table

For summary data views:
1. Click "Advanced (STEP 6-7, 12-14, 1)" tab
2. Click "Process CJI5 with Pivot Table" button
3. Select CJI5 file
4. Choose save location
5. Processing creates TWO sheets:
   - Sheet 1: "Processed Data" - Original file with Amount_USD formulas
   - Sheet 2: "Pivot Table" - Summary pivoted by Reference Document with calculated USD values

7.4 Feature 3: CJI3 Processing

7.4.1 What is CJI3?
CJI3 is another financial reference document, similar to CJI5 but with different 
column names or data structure.

7.4.2 Differences from CJI5
- CJI3 uses different column names (e.g., "Purchasing Document" vs "Reference Document")
- Processing logic adapted for CJI3 format
- Both use similar currency conversion and reference formatting
- Output format and benefits are identical to CJI5

7.4.3 When to Use
Use this feature specifically for CJI3 formatted files. Do not use CJI5 processor 
for CJI3 files, as column names may not match.

7.4.4 Step-by-Step Instructions

The process is identical to CJI5:
1. Open CAPEX Reporting Tool
2. Click "CJI3" tab (not CJI5!)
3. Click "Browse File"
4. Select your CJI3 Excel file
5. Click "Open"
6. Click "Process File"
7. Choose save location and filename
8. Click "Save"
9. Processing completes in 1-2 seconds
10. Success message displays results

7.4.5 File Requirements for CJI3

Your CJI3 file must contain these exact columns:
- Purchase Document field (or "Purchasing Document Number")
- Transaction Currency
- Value/Amount field
- Additional transaction data

7.4.6 Output Format

- File named: CJI3_Processed_[date]_[time].xlsx
- Structure identical to CJI5 output
- All formulas editable
- Ready for use
- Estimated Time of Processing: 1-3 seconds

7.4.7 Advanced: CJI3 with Pivot Table

For summary data views:
1. Click "Advanced (STEP 6-7, 12-14, 1)" tab
2. Click "Process CJI3 with Pivot Table" button
3. Select CJI3 file
4. Processing creates TWO sheets with formulas and pivot summary

7.5 Feature 4: RFP Processing

7.5.1 What is RFP?
RFP (Request for Payment) files contain procurement and financial data for 
proposal requests and approvals.

7.5.2 When to Use
Use this feature when you need to process RFP files and apply currency conversion.

7.5.3 File Requirements

Your RFP file must contain:
- Proposal Reference number
- Transaction Currency
- Amount/Value field
- Proposal details or descriptions

7.5.4 Step-by-Step Instructions

1. Open CAPEX Reporting Tool
2. Click on the "RFP" tab
3. Click "Browse File"
4. Select your RFP Excel file
5. Click "Open"
6. Note: You may see an option "Remove M-CBIP-25 entries" (optional checkbox)
   - If checked: removes entries marked as M-CBIP-25 category
   - If unchecked: keeps all entries (default)
   - Leave unchecked unless specifically instructed
7. Click "Process File"
8. Save dialog opens
9. Choose save location
10. Enter filename or use default "RFP_Processed_[date]_[time]"
11. Click "Save"
12. Processing completes (1-2 seconds)
13. Success message appears with file information

7.5.5 What the Processing Does

- Validates RFP data structure
- Adds USD Amount column with conversion formula
- Optionally removes M-CBIP-25 entries if selected
- Calculates total amount (all entries summed)
- Total appears in processed file
- All formulas editable

7.5.6 The M-CBIP-25 Option

CBIP entries are a specific category in RFP files:
- By default, processor keeps all entries (checkbox unchecked)
- Some workflows require removing CBIP entries
- Only check this box if instructed by your manager

7.5.7 Output Format

- File named: RFP_Processed_[date]_[time].xlsx
- Contains all RFP data with USD conversion formulas
- Total amount row included at bottom
- All amounts in USD (converted using same rates as CJI)
- Ready for proposal review and approval
- Estimated Time of Processing: 1-3 seconds

7.6.3 File Requirements

7.7 Feature 6: ZMM Processing

7.7.1 What is ZMM?
ZMM files handle procurement and Purchase Requisition (PR) reference data from 
the materials management system.

7.7.2 When to Use
Use this feature when you need to clean up PR numbers and standardize reference data.

7.7.3 File Requirements

Your ZMM file must contain:
- Ariba PR Reference number (main identifier)
- PR contains version numbers (v1, v2, v3, etc.) that need to be removed
- Additional purchase or vendor information

7.7.4 Step-by-Step Instructions

1. Open CAPEX Reporting Tool
2. Click on the "ZMM" tab under "Basic Processing (STEP 4-5)"
3. Click "Browse File"
4. Select your ZMM Excel file
5. Click "Open"
6. File is validated automatically
7. Click "Process File"
8. Save dialog opens
9. Choose save location and filename
10. Click "Save"
11. Processing completes (1-2 seconds)
12. Success message displays results

7.7.5 What the Processing Does

- Extracts PR numbers from Ariba references
- Removes version suffixes (v1, v2, v3, etc.) using formula
- Example: "PRN123456v2" becomes "PRN123456"
- Creates new column with cleaned PR number
- Converts cleaned PR to numeric format for sorting/analysis
- Creates duplicate column for reference
- Copies PO (Purchase Order) number if available
- Copies Vendor information if available
- All processing uses formulas (editable)

7.7.6 Output Structure

The processed file includes these new columns:
- PR Reference Delimited: PR number with version removed (text format)
- PR Reference Numeric: PR number converted to number format
- PR Reference Copy: Duplicate of cleaned PR
- PO Copy: Duplicate of PO number (if exists)
- Vendor Copy: Duplicate of vendor name (if exists)

7.7.7 Example Data

Original: "P-123456v3"
After Processing:
- Delimited: "P-123456"
- Numeric: 123456 (can be sorted as number)

7.7.8 Output Format

- File named: ZMM_Processed_[date]_[time].xlsx
- Contains all original data plus new columns
- All new columns contain formulas
- Ready for consolidation or analysis
- PR numbers now standardized and sortable
- Estimated Time of Processing: 2-5 seconds

8. TROUBLESHOOTING AND FAQ
================================================================================

8.1 Common Issues and Solutions

8.1.1 Issue 1: File Selection Not Working

Problem: Clicking the "Browse File" button does nothing, or the window closes 
unexpectedly.

Solutions:
- Make sure you have file selection permission:
  - Windows: Run as Administrator if prompted
  - macOS: Check System Preferences > Security & Privacy
- Try using a different folder:
  - Don't select from restricted locations
  - Save your file to Documents or a custom folder first
- Restart the application:
  - Close completely, wait 10 seconds, reopen

8.1.2 Issue 2: File Validation Error

Problem: After selecting the file, you get error message like "Invalid file 
structure" or "Missing columns."

Solutions:
- Verify correct file type:
  - Are you using CJI5 for a CJI3 file? (use correct tab)
  - Check the file name for version information
- Verify file format:
  - File must be .xlsx or .xls (Excel format)
  - Not .csv, .txt, or other formats
- Check file contents:
  - Open file in Excel first
  - Verify all required columns exist
  - Check column headers match expected names exactly
  - Delete empty rows or columns at top
- Save file properly:
  - Open file in Excel
  - Use File > Save As > Excel format (.xlsx)
  - Close file, try processing again

8.1.3 Issue 3: Processing Takes Very Long

Problem: After clicking "Process File," the application appears to freeze or shows 
loading screen for many minutes.

Solutions:
- Wait a bit longer:
  - Formula-based processing is typically fast (1-2 seconds)
  - Very large files (1M+ rows) may need longer
- Restart if frozen more than 5 minutes:
  - Force close the application
  - Windows: Use Ctrl+Alt+Delete, select Task Manager
  - macOS: Use Command+Q or Force Quit (Command+Option+Esc)
- Reduce file size and try again:
  - If file has millions of rows, split into smaller files

8.1.4 Issue 4: Cannot Find Processed File

Problem: Processing completes but cannot locate the saved file.

Solutions:
- Check save location:
  - During save dialog, notice which folder is shown
  - That's where your file was saved
- Windows file search:
  - Click Start menu, type filename or "CJI5_Processed"
  - Files menu shows all matches
- macOS file search:
  - Click Spotlight (magnifying glass, upper right)
  - Type filename, click on file in results
- Default locations to check:
  - Windows: C:\Users\[YourName]\Documents\
  - macOS: /Users/[YourName]/Downloads

8.1.5 Issue 5: Cannot Open Processed File in Excel

Problem: Processed file opens but shows errors or formulas don't calculate.

Solutions:
- Enable formulas in Excel:
  - Open file in Excel
  - If dialog appears about formulas, click "Enable"
  - Excel processes all formulas automatically
- Check Excel version:
  - File requires Excel 2016 or newer
  - Try opening in newer Excel or LibreOffice/Google Sheets
- File is corrupted:
  - Delete the file, reprocess original file

8.1.6 Issue 6: Wrong Data in Output

Problem: Processed file contains incorrect data, wrong calculations, or missing entries.

Solutions:
- Verify input file is correct:
  - Is this the right original file?
  - Does the file contain the data you expected?
  - Are column names spelled correctly?
- Check for hidden rows/columns:
  - Open original file in Excel
  - Unhide any hidden rows (right-click row numbers, select Unhide)
  - Unhide any hidden columns
- Re-process the file:
  - Verify file format is .xlsx, all required columns exist
  - Process again

8.1.7 Issue 7: Application Won't Open

Problem: Double-clicking the application does nothing, or crashes immediately.

Windows Solutions:
- Restart your computer (may resolve temporary issues)
- Reinstall the application:
  - Uninstall: Programs > Programs and Features > Uninstall
  - Redownload from Google Drive, install fresh
- Run as Administrator:
  - Right-click the application shortcut
  - Select "Run as Administrator"

macOS Solutions:
- Right-click → Open method (First Time Only):
  - Open Finder > Downloads
  - Right-click CAPEX_Reporting_Tool.app
  - Select "Open"
  - Click "Open" in security dialog
- Terminal command (if right-click didn't work):
  sudo xattr -rd com.apple.quarantine /Applications/CAPEX_Reporting_Tool.app
- Move app to Applications:
  - Drag CAPEX_Reporting_Tool.app from Downloads to Applications folder
  - Try running from Applications
- Restart your Mac:
  - Close all applications, restart computer, try opening app again

8.1.8 Issue 8: Update Failed or Stuck on Old Version

Problem: Application doesn't update to newest version, or update process seems stuck.

Solutions:
- Manual restart:
  - Close the application completely
  - Reopen it - should fetch latest version automatically
- Clear update cache:
  - Windows: Delete %AppData%\CAPEX folder if exists
  - macOS: Delete ~/Library/Application Support/CAPEX folder if exists
- Manual update:
  - Download latest version from GitHub releases
  - Run the installer (replaces old version)
  - Restart the app

8.1.9 Issue 9: Formulas Show as Text Instead of Calculating

Problem: Processed file shows formulas as text (e.g., "=IF(A1..." visible) instead 
of calculated values.

Solutions:
- Format column as number:
  - Select the column
  - Right-click > Format Cells
  - Click "Number" tab
  - Change format to "Number"
- Recalculate formulas:
  - Press Ctrl+Shift+F9 (Windows) or Cmd+Shift+F9 (macOS)
- Check Excel settings:
  - File > Options > Formulas
  - Make sure "Show formulas" is NOT checked

8.1.10 Issue 10: File Size Seems Too Large

Problem: Processed file is much larger than expected, takes long to open.

Explanation: This is normal and expected:
- Original file: What you started with
- Processed file: Original data + new formula columns
- Formulas add size to file
- Larger file = more comprehensive processing
- Still opens quickly once formulas calculate

Solution: File size is not a problem. This is normal operation.
